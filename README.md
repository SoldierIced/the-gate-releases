# The Gate: test builds

Binaries of the first-person wave-defense game **The Gate** for friends who test it before the Steam release. The source code is private.

## Install

- Windows: download `the-gate-win-<version>.zip` from the latest release, unzip it anywhere and run `win\Game.exe`. SmartScreen may ask once: More info, then Run anyway.
- macOS: download `the-gate-mac-<version>.zip`, unzip it and open `The Gate.app`. The app is not signed: the first time, right-click it and choose Open.

## Updates

The game checks this repository when it starts and offers the newest build from the main menu: one click downloads it, verifies it and restarts the game. `latest.json` on each release is what the game reads.
